Beginner

week 1-2
Sites & navigation
A1✓ mastered15 mintap ▸
Navigate a site and understand hub sites vs. site collections
Every SharePoint site lives in a hierarchy — hub sites group related sites together for shared navigation and branding, while each site itself is still its own permission and storage boundary. Knowing which one you're in changes where content and permissions actually live.
Site contents (gear icon) → see lists, libraries, and pages in this site Site information → check if this site is associated with a hub Hub site nav bar at the top links out to associated sites
A2✓ mastered20 mintap ▸
Create a document library and upload, organize files
A document library is where files live with metadata, version history, and permissions attached — not just a folder in an email attachment. Getting comfortable with drag-and-drop upload, folders vs. metadata, and the library ribbon is the foundation for everything else.
New → Document Library, name it Drag files from File Explorer straight into the library Use columns (metadata) instead of nested folders to organize when possible
Lists, libraries & sharing
A3✓ mastered20 mintap ▸
Create a custom list and add columns
A list is SharePoint's structured-data building block — think of it as a lightweight, shareable spreadsheet with real column types (choice, person, date, lookup) instead of just text in cells.
New → List → Blank list, name it Add column → pick a type: Single line of text, Choice, Person, Date Use Quick Edit (grid view) to fill in rows fast, like Excel
A4✓ mastered15 mintap ▸
Sort, filter, and group with views
A view is a saved way of looking at the same list or library — filtered to what matters, sorted the way you read it, grouped so related rows sit together. Different people can have different views of the same data without duplicating it.
List/library toolbar → Add view, name it (e.g. 'My open items') Filter by column (e.g. Status = Open) Group by → e.g. group by Assigned To
A5✓ mastered15 mintap ▸
Share a file or folder with the right permission level
Sharing decides who can get in, but the permission level decides what they can do once inside. Handing out Edit access by default, when someone only needed to view a file, is the most common oversharing mistake.
Select a file → Share → enter names or 'Anyone with the link' Click the pencil next to the link to choose Can edit / Can view Check existing access anytime via Manage access

COLUMN B

Intermediate

week 3-5
Structure & customization
B1✓ mastered25 mintap ▸
Site structure: subsites vs. hub associations
Subsites nest inside a parent site and inherit some of its structure; hub associations instead link independent, flat sites together under shared navigation. Microsoft now recommends flat sites joined via hubs over deep subsite trees, because subsites are harder to move, secure, and migrate later.
Recommended: create a flat site → SharePoint admin center → Hub sites → associate it to the right hub Legacy pattern (avoid for new builds): Site contents → New → Subsite
B2✓ mastered25 mintap ▸
Content types and site columns for consistent metadata
A site column is a reusable field definition; a content type bundles several site columns (plus behavior, like a template) into a reusable 'kind of item' — like Contract or Invoice — that stays consistent across every library it's attached to.
Site settings → Site columns → New column, define it once Site settings → Content types → New → add the site columns you built Library settings → Add from existing content types → attach it
B3✓ mastered20 mintap ▸
Library settings: versioning, check-out, and alerts
Versioning keeps every prior copy of a file recoverable; check-out locks a file so only one person edits it at a time; alerts notify people when something changes — three separate safety nets that prevent overwritten work and missed updates.
Library settings → Versioning settings → turn on major/minor versions Library settings → Require check-out Library/list → ... → Alert me → choose when to be notified
B4✓ mastered30 mintap ▸
Format views and columns with column formatting (JSON)
Column formatting lets you change how a column renders — color-coded status pills, icons, conditional highlighting — without touching the underlying data, using a small JSON snippet applied through the column settings.
Column header dropdown → Column settings → Format this column Paste JSON with an elmType and conditional style rules Preview updates live before you save
Column formatting pipeline
Access & automation
B5✓ mastered25 mintap ▸
Permission levels, SharePoint groups, and breaking inheritance
By default, everything inside a site inherits its permissions from the site itself. Breaking inheritance on a specific library or item gives it its own independent permission set — powerful, but it's also how permission sprawl and confusing access starts.
Library/item → ... → Manage access → Stop Inheriting Permissions Add people through a SharePoint group (e.g. 'Marketing Members'), not individual names Site permissions page shows every group and its permission level at a glance
B6✓ mastered25 mintap ▸
Build a basic Power Automate flow from a list
Power Automate connects a trigger — like a new list item — to actions like sending an email or starting an approval, without writing code. Most first flows automate the notification or approval step people were doing manually.
List → Automate → Power Automate → Create a flow Pick a trigger: 'When an item is created' Add an action: 'Send an email' or 'Start an approval'

Advanced

week 6-9
Power Platform
C1✓ mastered35 mintap ▸
Customize a list form with Power Apps
The default SharePoint list form is generic; Power Apps lets you replace it with a fully custom layout — conditional fields, validation, better grouping — without leaving the list.
List → Integrate → Power Apps → Customize forms Select a control (e.g. a data card) → change its Visible property with a formula Publish to SharePoint to replace the default form
C2✓ mastered35 mintap ▸
Multi-step Power Automate flows with approvals and conditions
Real business processes branch — approve or reject, notify different people depending on a value. Conditions and the Approvals connector are what let a flow make decisions instead of running the same steps every time.
Add a Condition action: If [Amount] is greater than 1000 → branch Start and wait for an approval → assign an approver Use the approval outcome to branch the next actions
Flow branching on a condition
Governance & search
C3✓ mastered25 mintap ▸
Managed metadata and the term store
The term store is a centrally managed, hierarchical vocabulary — like a company-wide list of approved department names or product lines — that keeps tagging consistent across every site, instead of everyone typing their own variations.
SharePoint admin center → Content services → Term store Create a term set, e.g. 'Departments' → add terms: Finance, Marketing, Operations On a library, add a Managed Metadata column pointing at that term set
C4✓ mastered30 mintap ▸
Search: managed properties, refiners, and promoted results
Search results are built from crawled properties mapped to managed properties — the fields you can actually search, sort, and filter by. Refiners expose those as filter panels, and promoted results pin a specific answer to the top for a given query.
SharePoint admin center → Search → Manage search schema Map a crawled property to a managed property, mark it Refinable Search results page → add a promoted result for a common query, like 'benefits' → HR portal
C5✓ mastered25 mintap ▸
Automate document processing with SharePoint Syntex
Syntex uses AI models to read incoming documents — invoices, contracts, forms — and automatically extract metadata or classify them, replacing manual tagging for high-volume, repetitive document types.
SharePoint admin center → Syntex → create a content center Train a model on sample documents (e.g. invoices) and the fields to extract Apply the model to a library so new uploads get classified and tagged automatically
C6✓ mastered30 mintap ▸
Provision and manage sites with PnP PowerShell
PnP PowerShell is the community-maintained toolkit for scripting SharePoint administration — creating sites, applying templates, bulk-updating settings — anything that's tedious or error-prone to click through by hand.
Connect-PnPOnline -Url https://contoso.sharepoint.com/sites/team -Interactive New-PnPSite -Type TeamSite -Title 'Project Falcon' -Alias projectfalcon Get-PnPList | Where-Object Hidden -eq $false
Compliance & scale
C7✓ mastered25 mintap ▸
Retention labels and records management
A retention label tells SharePoint how long to keep content and what to do afterward — delete, review, or keep as a record — which is how organizations meet legal and compliance requirements without relying on people remembering to clean up manually.
Microsoft Purview compliance portal → Records management → Retention labels Create a label: retain 7 years, then delete Publish the label to a library, or auto-apply it based on content type or keywords
C8✓ mastered25 mintap ▸
Hub sites and information architecture at scale
As an organization grows past a handful of sites, hub sites become the backbone of navigation and branding — rolling up news, search, and nav across dozens of associated sites so people don't need to know the exact URL of every team site.
SharePoint admin center → Hub sites → Register a hub site Sites → Site information → Associate with a hub Hub navigation → configure the shared nav links every associated site inherits

Expert

week 10-14
Development
D1✓ mastered45 mintap ▸
Build and deploy a custom web part with the SPFx
The SharePoint Framework (SPFx) is the modern way to build custom, client-side web parts using standard web tools like TypeScript and React, packaged and deployed through the app catalog to any site.
yo @microsoft/sharepoint (Yeoman generator) → scaffold a new web part gulp bundle --ship && gulp package-solution --ship Upload the .sppkg to the tenant or site App Catalog
D2✓ mastered30 mintap ▸
Tenant sharing and access settings in the SharePoint admin center
Tenant-level sharing settings set the ceiling for what's possible anywhere in the organization — if external sharing is off at the tenant level, no individual site can turn it on. Getting this wrong either locks out legitimate collaboration or opens the door too wide.
SharePoint admin center → Policies → Sharing Set external sharing level: Anyone / New and existing guests / Existing guests / Only people in your organization Conditional Access policies layer additional device/location restrictions on top
Sharing ceiling: tenant vs. site
D3✓ mastered35 mintap ▸
Automate SharePoint with the Microsoft Graph API
Microsoft Graph is the unified REST API across Microsoft 365 — sites, lists, files, permissions — letting you automate and integrate SharePoint from any external application, not just PowerShell or Power Automate.
GET https://graph.microsoft.com/v1.0/sites/{site-id}/lists Authenticate via an Azure AD app registration with the right Sites.* permission scope Use delta queries to sync only what's changed since the last check
Compliance & migration
D4✓ mastered30 mintap ▸
Sensitivity labels and DLP policies
Sensitivity labels classify and protect content — encrypting it or restricting sharing, based on how sensitive it is — while Data Loss Prevention (DLP) policies actively detect and block sensitive data (like credit card numbers) from leaving in the first place.
Microsoft Purview compliance portal → Information protection → Labels → create a 'Confidential' label with encryption Data loss prevention → Policies → create a rule detecting patterns like credit card numbers Publish the label policy to the SharePoint sites that need it
D5✓ mastered35 mintap ▸
Provision sites at scale with PnP templates and site scripts
A PnP site template captures a site's structure — lists, libraries, columns, permissions — as reusable XML/JSON so new sites can be provisioned consistently instead of rebuilt by hand every time. Site scripts do something similar natively, tied to site designs in the UI.
Get-PnPSiteTemplate -Out template.xml (capture an existing, well-built site) Invoke-PnPSiteTemplate -Path template.xml (apply it to new sites) Or: register a native Site Script + Site Design for self-service provisioning in the UI
D6✓ mastered40 mintap ▸
Plan and execute a content migration
A migration isn't just moving files — it's mapping permissions, metadata, and version history from a source (file shares, another platform, another tenant) into SharePoint's structure, ideally without users noticing the seams.
Inventory the source: file counts, path depth, permission complexity SharePoint Migration Tool (or a third-party tool) for the bulk file/metadata move Run a pilot migration on a small folder first, validate, then scale up
Enterprise administration
D7✓ mastered30 mintap ▸
Multi-geo and performance considerations at scale
Large or regulated organizations sometimes need data to physically reside in specific geographic regions — multi-geo lets a single tenant span satellite locations while keeping each geography's data resident there, which also affects latency and performance for users far from the primary region.
Microsoft 365 admin center → Multi-Geo → configure satellite geo locations Assign users to a Preferred Data Location (PDL) attribute Monitor performance/latency separately per geo, not just tenant-wide
D8✓ mastered30 mintap ▸
Write a governance plan: naming, lifecycle, ownership
Without a governance plan, site sprawl happens by default — inconsistent naming, no clear owner, sites that outlive their purpose. A written plan sets the naming conventions, who approves new sites, and what happens when a site goes stale.
Define a naming convention (e.g. [Dept]-[ProjectName]) enforced via a site design/script Assign a required Owner for every new site, checked at creation Set an inactive-site policy: flag sites with no activity in 12 months for review
D9✓ mastered25 mintap ▸
Monitor usage and troubleshoot with admin reports and logs
Usage reports show what's actually being used (or ignored), while sign-in and audit logs are what you reach for when something goes wrong — a permission that mysteriously changed, a site that suddenly stopped syncing.
Microsoft 365 admin center → Reports → SharePoint site usage Microsoft Purview → Audit → search for a specific user/file/date range event Microsoft Entra sign-in logs → check for blocked or conditional-access-denied sign-ins
