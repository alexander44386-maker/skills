Compose a message and use To vs. Cc vs. Bcc correctly
Every message starts here, and the recipient fields carry real meaning: To is for people who need to act, Cc is a visible FYI copy, and Bcc hides that address from everyone else on the message.
Home → New Email To = people who need to respond or act Cc = people who just need visibility (everyone can see they're copied) Bcc = a hidden copy — the other recipients never see that address was included

Contact Lists / Contact Groups
New: Contact List · Classic: Contact Group
Emailing the same dozen people every week? Saving them under one name lets you type it once and reach everyone, and updates for the whole team the moment you edit the membership. This is a personal address-book feature — it's not the same thing as a Microsoft 365 Group, which is a full shared workspace with its own inbox, calendar, and files.
New Outlook: People → New Contact List Classic Outlook: People (Contacts) → New Contact Group Add Members → From Outlook Contacts / Address Book Type the list/group's name in the To field of a new email to reach everyone at once
⚠️ New Outlook calls this a Contact List; Classic Outlook calls it a Contact Group — same feature, different name. Neither is a Microsoft 365 Group, which is a separate, admin-provisioned shared workspace (inbox + calendar + files), not just a saved recipient list.

Server-side vs. client-side rules, and rule limits
Classic & New Outlook
A rule that depends on an action Outlook itself performs (like a sound alert or moving to a local .pst) only runs while Outlook is open on your machine. A rule Exchange can execute entirely on the server keeps working even when you're logged off.
Manage Rules & Alerts → rules with a small gear/warning icon only run client-side Mailbox rule storage is capped — too many complex rules can silently stop new ones from saving When possible, prefer conditions/actions Exchange can execute server-side

Shared mailboxes & permissions
D2LearnRecallApplyMaster35 minCLICK TO LEARN →
Shared mailboxes & delegation: Full Access, Send As, Send on Behalf
Exchange Admin Center
These are three different permissions, not three names for the same thing. Delegate access shares your own calendar/inbox with someone; a shared mailbox is a separate mailbox multiple people work out of; and Send As / Send on Behalf control how a message from that shared mailbox looks to the recipient. Mixing them up either over-shares access or leaves someone unable to do the job they were given.
Delegate access — File → Account Settings → Delegate Access, on YOUR OWN mailbox; shares your calendar/inbox/tasks with someone else Shared mailbox — a separate mailbox a team works from; granted via Exchange admin center → Recipients → Mailboxes → shared mailbox → Delegation Full Access — lets someone open and work inside the shared mailbox itself, like it's their own Send As — message appears to come only from the shared mailbox (no "on behalf of") Send on Behalf — message shows "YourName on behalf of SharedMailbox"; in work/school accounts, Send As usually needs an admin to grant it

Data retention
D3ALearnRecallApplyMaster15 minCLICK TO LEARN →
Personal archiving with AutoArchive
Classic Outlook only
AutoArchive is a personal, local Outlook setting — it sweeps old items out of your mailbox and into a .pst on your machine before you hit your size limit. It's about keeping your own mailbox tidy, and it has nothing to do with what your organization is legally required to keep.
File → Options → Advanced → AutoArchive Settings → set the age and destination Right-click a folder → Properties → AutoArchive to override the default per folder Runs locally on one device — items archived on your desktop won't show up in OWA or on another PC
⚠️ AutoArchive is a Classic Outlook desktop feature and isn't available in New Outlook or on the web. It's your setting, not your organization's policy — see D3B.
🔧 4. Practice
🏆 Master — scenario
D3BLearnRecallApplyMaster20 minCLICK TO LEARN →
Organizational retention with Microsoft Purview
Microsoft Purview / Admin
A retention policy is set by your organization, applies to everyone it targets, and can't be turned off from inside Outlook. Retention labels go a step further, letting someone tag individual items or folders with their own retention rule. This is the layer that actually satisfies legal or compliance requirements — your personal AutoArchive setting does not.
Microsoft Purview compliance portal → Data lifecycle management → Retention policies, for org-wide rules Retention labels apply to specific items/folders and can trigger deletion, retention, or a review Applies regardless of client (desktop, New Outlook, OWA, mobile) — it's enforced server-side
⚠️ Don't rely on AutoArchive (D3A) for anything that must be legally retained — that requires an org-level Purview retention policy or label instead.

Diagnostics & maintenance
D5LearnRecallApplyMaster25 minCLICK TO LEARN →
Audit mailbox size with Mailbox Cleanup
Classic Outlook only
Before blaming slow sync or a bloated .ost on "Outlook being Outlook," check what's actually taking up space — a handful of huge attachments are almost always the real culprit.

Diagnose sync, Cached Mode & search index issues
Classic Outlook only
"Outlook is broken" is rarely the real diagnosis. A mailbox that looks stale, a search that returns nothing, or a folder stuck mid-sync almost always traces back to one of three things: Cached Exchange Mode being out of sync, a stuck Send/Receive, or a corrupted search index — and each has its own specific fix, not a reinstall.
File → Account Settings → account → Change → check whether Cached Exchange Mode is on and how much mail it's set to keep offline Send/Receive tab → Send/Receive Groups → Define Send/Receive Groups to force a manual sync and watch for stuck items Control Panel → Indexing Options → Advanced → Rebuild, if search returns incomplete or no results even for mail you know exists
⚠️ Cached Exchange Mode settings and the local search index are Classic Outlook (desktop) concepts. New Outlook and OWA always work against the server copy directly, so there's no local cache or index to rebuild. For repairing a corrupted local .ost/.pst file specifically, see the optional ScanPST lab under Labs.
