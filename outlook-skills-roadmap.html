Beginner

week 1–2
Composing & sending
A1✓ mastered20 mintap ▸
Compose a message and use To vs. Cc vs. Bcc correctly
Every message starts here, and the recipient fields carry real meaning: To is for people who need to act, Cc is a visible FYI copy, and Bcc hides that address from everyone else on the message.
Home → New Email To = people who need to respond or act Cc = people who just need visibility (everyone can see they're copied) Bcc = a hidden copy — the other recipients never see that address was included
A2✓ mastered20 mintap ▸
Attach files and insert a signature
A message with a broken or forgotten attachment is one of the most common (and avoidable) email mistakes. A saved signature means you never retype your sign-off by hand again.
Message tab → Attach File → Browse This PC (or Browse Web Locations for a cloud file) Insert tab → Signature → set up once under Signatures and pick a default for new messages and replies
Staying organized
A3✓ mastered15 mintap ▸
Create folders and move mail into them
A flat inbox with thousands of messages makes anything hard to find later. Folders (and the drag-and-drop or right-click Move to move mail into them) are the simplest form of organization, and everything more advanced builds on this.
Right-click your inbox (or account name) → New Folder Drag a message onto a folder in the left pane to file it Home tab → Move → pick a folder as a faster alternative to dragging
A4✓ mastered15 mintap ▸
Flag messages and use Focused Inbox
A flag marks something as needing a reply later without you having to remember it. Focused Inbox automatically splits mail you usually engage with from newsletters and bulk mail, so the important stuff doesn't get buried.
Click the flag column next to any message to mark it for follow-up View tab → Show Focused Inbox toggles the Focused/Other split on or off Drag a wrongly-sorted message between the Focused and Other tabs to retrain it
Finding your way around
A5✓ mastered15 mintap ▸
Know the Ribbon tabs, Conversation view, and switching modules
New users often don't know where anything lives. The Ribbon changes tabs depending on what's selected, Conversation view collapses a whole reply thread into one line, and the bottom-left icons switch between Mail, Calendar, People, and Tasks.
Bottom-left icons (or Ctrl+1/2/3/4) switch between Mail, Calendar, People, Tasks View tab → Show as Conversations groups a thread's replies into one expandable item The Ribbon's tabs (Home, Send/Receive, Folder, View) change based on what's selected

COLUMN B

Intermediate

week 3–5
Automating your inbox
B1✓ mastered30 mintap ▸
Build an inbox rule with the Rules Wizard
The single highest-leverage habit in this whole column: instead of manually filing the same kind of email every day, describe the condition once and let Outlook file it forever.
Home tab → Rules → Manage Rules & Alerts → New Rule Rules Wizard → pick a condition (e.g. from a specific sender) → pick an action (e.g. move to a folder) Finish → Apply rule now (optional) to run it on mail already in the inbox
Rule flow — condition, then action, in order
B2✓ mastered20 mintap ▸
Bundle actions with Quick Steps
A rule reacts automatically to incoming mail; a Quick Step is a one-click button you trigger yourself — perfect for a repeated multi-step reply-and-file action you do manually all day.
Home tab → Quick Steps gallery → Create New Name it, then stack actions like "Move to folder" + "Mark as read" + "Flag for follow-up" Optionally assign a keyboard shortcut so it's one keypress instead of one click
Calendar & meetings
B3✓ mastered25 mintap ▸
Schedule a meeting with the Scheduling Assistant
Guessing at a time slot and getting three reschedule replies wastes everyone's time. Scheduling Assistant lays out every invitee's free/busy time side by side so you can pick a slot that actually works.
New Meeting → Scheduling Assistant tab Add attendees, look for the widest all-clear column across their calendars Drag the meeting block to that slot, then switch back to Appointment to send
B4✓ mastered15 mintap ▸
Categorize and color-code with Quick Click
Categories turn a flat inbox into something you can visually scan by project or urgency — and Quick Click lets you stamp your most-used category with a single click on the category column, no menu required.
Right-click the category column next to any message → Set Quick Click Click that column on any message to apply your default category instantly View → Arrange By → Categories to group the whole list by color
Templates & sharing
B5✓ mastered20 mintap ▸
Build reusable signatures and message templates (.oft)
A signature handles the sign-off automatically on every message. A saved .oft template goes further — the whole body, subject, and formatting of a message you send often, ready to reuse in two clicks instead of retyping.
File → Options → Mail → Signatures → create and set defaults per account Draft a message → File → Save As → Outlook Template (.oft) to reuse it later New Items → More Items → Choose Form → look in User Templates to reopen it
B6✓ mastered25 mintap ▸
Grant delegate access to your mailbox
When someone else needs to manage your calendar or send mail on your behalf — an assistant covering meetings while you're out, for example — delegate access is the supported way to hand over exactly that much control.
File → Account Settings → Delegate Access → Add Pick the delegate and set their permission level per folder (Calendar, Inbox, Tasks) Choose whether they see private items, and whether they get meeting request copies

COLUMN C

Advanced

week 6–9
Meetings at scale
C1✓ mastered30 mintap ▸
Recurring meetings & Room Finder
A weekly standup shouldn't be five separate invites. Recurrence handles the repeating pattern in one invite; Room Finder shows which conference rooms are actually free instead of you guessing and getting double-booked.
New Meeting → Recurrence button → set pattern (daily/weekly/monthly) and end date Scheduling Assistant → Room Finder pane → pick a free room, it's added as a resource automatically
C2✓ mastered30 mintap ▸
Multi-condition rules & Run Rules Now
Real rules usually need more than one condition — from a specific sender AND with an attachment AND over a certain size. Run Rules Now lets a brand-new rule clean up messages that already arrived, instead of only future mail.
Rules Wizard → stack multiple "from/with/containing" conditions with AND logic Manage Rules & Alerts → Run Rules Now → pick the rule and a folder to apply it to retroactively
Bulk communication
C3✓ mastered30 mintap ▸
Mail merge from Word using an Outlook contacts list
One personalized email to 200 people, each addressed by name, without 200 manual sends — mail merge pulls from an Outlook contact list or Excel sheet and lets Word send them through your Outlook profile.
Word → Mailings tab → Select Recipients → Choose from Outlook Contacts Insert Merge Fields (like «FirstName») into the message body Finish & Merge → Send E-Mail Messages → sends individually through Outlook
C4✓ mastered20 mintap ▸
Automatic Replies with internal/external rules
A single generic Out-of-Office reply isn't always right — you often want a warmer, detailed message for coworkers and a shorter, vaguer one for outside senders, and Automatic Replies supports both from one screen.
File → Automatic Replies (Out of Office) Set separate message text under the "Inside My Organization" and "Outside My Organization" tabs Optionally add rules (e.g. auto-forward or flag) that only apply while replies are on
Search & security
C5✓ mastered25 mintap ▸
Advanced search operators & Search Folders
Typing a name into the search box only gets you so far. Operators let you search precisely (attachments, date ranges, unread), and a Search Folder saves that exact query as a live, self-updating virtual folder.
Search box: from:boss hasattachments:yes received:lastweek Search tab → Search Tools → New Search Folder → base it on a saved query A Search Folder shows matching mail from anywhere without moving or duplicating it
C6✓ mastered20 mintap ▸
Recognize and report phishing/junk mail
A convincing phishing email can cost real money or credentials. Reporting it (not just deleting it) helps Microsoft's filters catch the same sender for everyone else, and blocking stops repeat offenders from reaching you again.
Home tab → Report → Report Phishing / Report Junk Home tab → Junk → Block Sender to stop future mail from that address Hover, don't click, any suspicious link to preview the real destination URL first
Extending Outlook
C7✓ mastered20 mintap ▸
Install and manage Store add-ins
Add-ins bring outside tools (schedulers, CRMs, e-signature, translation) directly into the Outlook ribbon or reading pane, instead of you copy-pasting between apps all day.
Home tab → Get Add-ins (or Apps for Outlook) Browse or search the store, click Add for the one you need Manage installed add-ins from File → Manage Add-ins if one starts causing problems
C8✓ mastered20 mintap ▸
Build and maintain Contact Groups
Emailing the same dozen people every week? A Contact Group lets you type one name and reach everyone in it, and updates for the whole team the moment you edit the membership.
People (Contacts) → New Contact Group Add Members → From Outlook Contacts / Address Book Type the group's name in the To field of a new email to reach everyone at once

COLUMN D

Expert

week 10–14
Automation & scripting
D1✓ mastered35 mintap ▸
Automate repetitive tasks with VBA macros
Anything you do the same way ten times a week — stamping a category, moving a class of messages, formatting a reply — is a candidate for a macro. VBA runs inside Outlook itself, no external tool required.
Developer tab → Visual Basic (or Alt+F11) opens the editor Insert → Module, then write a Sub that runs against the current mail item Assign the macro to a Quick Access Toolbar button or a keyboard shortcut
D2✓ mastered30 mintap ▸
Send As vs. Send on Behalf for shared mailboxes
Both let you send from a shared mailbox, but they read differently to the recipient — one hides you entirely, the other visibly credits you as the sender. Getting this wrong on a support or sales mailbox looks unprofessional fast.
Exchange admin center → Recipients → Mailboxes → shared mailbox → Delegation Send As: message appears to come only from the shared mailbox Send on Behalf: message shows "YourName on behalf of SharedMailbox"
Data lifecycle
D3✓ mastered30 mintap ▸
Retention policies & AutoArchive
Mailboxes don't clean themselves. A retention policy moves or deletes items on a schedule you define at the org level; AutoArchive does the same thing locally, sweeping old items into a .pst before your mailbox hits its size limit.
File → Options → Advanced → AutoArchive Settings → set the age and destination Exchange admin center → Compliance → Retention policies for org-wide rules Right-click a folder → Properties → AutoArchive to override the default per folder
D4✓ mastered25 mintap ▸
Server-side vs. client-side rules, and rule limits
A rule that depends on an action Outlook itself performs (like a sound alert or moving to a local .pst) only runs while Outlook is open on your machine. A rule Exchange can execute entirely on the server keeps working even when you're logged off.
Manage Rules & Alerts → rules with a small gear/warning icon only run client-side Mailbox rule storage is capped — too many complex rules can silently stop new ones from saving When possible, prefer conditions/actions Exchange can execute server-side
Diagnostics & maintenance
D5✓ mastered25 mintap ▸
Audit mailbox size with Mailbox Cleanup
Before blaming slow sync or a bloated .ost on "Outlook being Outlook," check what's actually taking up space — a handful of huge attachments are almost always the real culprit.
File → Tools (or Info) → Mailbox Cleanup View Mailbox Size to see folder-by-folder totals Find Items Older Than / Find Items Larger Than to target cleanup
D6✓ mastered30 mintap ▸
Build a Power Automate flow with the Outlook connector
Power Automate reaches beyond what a rule or Quick Step can do — save every attachment to OneDrive, post a Teams message when a VIP emails, or log new messages to a spreadsheet, all without writing code.
make.powerautomate.com → Create → Automated cloud flow Trigger: "When a new email arrives" (Outlook connector) Add actions like "Save attachment to OneDrive" or "Post message in Teams"
Platform & administration
D7✓ mastered25 mintap ▸
Outlook on the web vs. desktop, and admin center basics
Support tickets often hinge on knowing which Outlook someone means. OWA settings, desktop settings, and mobile settings don't always sync automatically, and some admin-level controls only exist in the Microsoft 365 admin center.
outlook.office.com signs into Outlook on the web (OWA) — same mailbox, separate settings surface Some org-wide controls (retention, mail flow, add-in deployment) only live in the admin center, not in either client When troubleshooting, always ask which client reproduces the issue
D8✓ mastered25 mintap ▸
Repair a corrupted profile with the Inbox Repair Tool (ScanPST)
A profile that won't open, search that returns nothing, or random crashes often trace back to a corrupted .ost/.pst — and the fix ships with Office, no download required.
Find ScanPST.exe (under the Office install path, e.g. Program Files\Microsoft Office\root\OfficeXX) Close Outlook, run ScanPST, browse to the .ost/.pst file, click Start Back up the file before repairing — the tool offers to, take it up on that
D9✓ mastered30 mintap ▸
Mail flow (transport) rules in the Exchange admin center
A personal inbox rule only affects your own mailbox. A transport rule runs on every message flowing through the organization — adding a legal disclaimer, blocking risky attachments, or rerouting mail company-wide.
Exchange admin center → Mail flow → Rules → new rule Conditions/actions apply org-wide, before mail ever reaches an inbox Common uses: append disclaimers, block executable attachments, redirect based on sender domain
